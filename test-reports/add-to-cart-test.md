# Add to Cart Feature Test

## Website
SauceDemo

## Feature Tested
Add to Cart and Remove from Cart

## Test Steps

1. Logged into the SauceDemo website using the provided test account.
2. Selected a product.
3. Clicked the "Add to cart" button.
4. Checked that the button changed to "Remove".
5. Checked that the cart icon showed 1 item.
6. Opened the shopping cart.
7. Verified that the correct product, name, and price were displayed.
8. Clicked "Remove" to remove the product.
9. Verified that the product was removed from the cart.

## Expected Result

- The selected product should be added to the shopping cart.
- The cart should display the correct number of items.
- The correct product information should appear in the cart.
- The product should be removed when clicking "Remove".

## Actual Result

All tested functions worked correctly.
