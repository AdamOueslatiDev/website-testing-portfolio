# Sample Bug Report

> This is a sample bug report created to demonstrate my understanding of professional bug reporting. This bug was not reported as a confirmed bug in SauceDemo.

## Bug ID

BUG-001

## Title

Shopping cart badge does not update after adding a product

## Severity

Medium

## Priority

Medium

## Environment

- Website: Example E-commerce Website
- Browser: Google Chrome
- Device: Desktop
- Operating System: Windows

## Preconditions

The user is logged into the website.

## Steps to Reproduce

1. Open the products page.
2. Select any product.
3. Click the "Add to Cart" button.
4. Look at the shopping cart icon.

## Expected Result

The shopping cart badge should update and display the number of items added to the cart.

## Actual Result

The product is added to the cart, but the shopping cart badge does not update.
